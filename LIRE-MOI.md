# Orezia Group — Version finale

## Héberger le site

Décompressez `orezia-site-final.zip`, puis déposez son contenu dans le répertoire public de votre hébergement. Le fichier `index.html` se trouve à la racine. Aucun logiciel, service tiers, compilation ou clé API n’est nécessaire.

Pour consulter le site sur votre ordinateur, ouvrez `index.html` dans votre navigateur. Toutes les images et tous les styles sont inclus.

## Contenu et design

Le header et le hero reprennent la référence fournie : crème, vert profond, titres gras, motif Orezia et photographie au bord de l’écran. Le reste de la page prolonge cette direction avec une famille de pictogrammes, le schéma Accès / Ressources / Refuges, un protocole en cinq étapes et un schéma de suivi.

Le parcours ACCA organise les sections : Attention (enjeux), Compréhension (environnements, 5D, méthode, nettoyage), Conviction (suivi, offres, FAQ), Action (diagnostic gratuit).

Aucun client, certification, performance chiffrée ou réalisation réelle n’a été inventé. Les illustrations générées sont légendées. Le rapport vide a été remplacé par un schéma explicatif sans champ manquant. Une rubrique Informations & confidentialité décrit les contacts et le fonctionnement du formulaire.
